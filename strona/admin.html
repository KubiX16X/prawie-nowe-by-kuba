Panel sklepu

Oznaczanie sprzedanych rzeczy

Jednorazowo wklej kod dostępu z GitHuba. Telefon go zapamięta.

  1. Na github.com: zdjęcie profilu → Settings → na samym dole Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. Nazwa np. panel sklepu, ważność: najdłuższa możliwa.
  4. Repository access: Only select repositories → prawie-nowe-by-kuba.
  5. Permissions → Contents: Read and write.
  6. Generate token, skopiuj kod (zaczyna się od github_pat_) i wklej niżej.

Kod zostaje tylko w tym telefonie. Bez niego nikt nie zmieni sklepu, nawet jeśli znajdzie tę stronę.
